## 3. Phạm vi và actor

Sáu nhóm nghiệp vụ: CUSTOMER (khách vô danh theo lượt), WAITER, KITCHEN, CASHIER, MANAGER, ADMIN. CUSTOMER không phải tài khoản nhân viên và không nằm trong bảng role nhân viên. Một nhân viên có thể có nhiều role; không mặc định một role kéo theo role khác.

Trong MVP, admin tạo tài khoản nhân viên, đặt lại mật khẩu tạm và khóa/mở tài khoản; người dùng đổi mật khẩu ở lần đăng nhập đầu. “Đăng ký” trong nguồn được hiểu là tạo tài khoản nội bộ, không mở tự đăng ký quyền nhân viên từ Internet. Không SSO, đăng nhập mạng xã hội, đăng ký thành viên hay tự khôi phục qua email.

## 5. Luồng chính

1. Nhân viên đăng nhập; server kiểm tra hash, active, giới hạn thử sai; tạo phiên bằng token ngẫu nhiên, chỉ lưu hash.
2. Trả cookie HttpOnly; UI lấy `/auth/me` để điều hướng đúng vai trò. Tài khoản bắt buộc đổi mật khẩu chỉ truy cập me/change-password/logout.
3. Mỗi API kiểm tra phiên và policy. Đăng xuất thu hồi phiên; cookie bị xóa.
4. Admin tạo/reset/đổi role trong transaction có kiểm tra ADMIN cuối cùng; phát audit. Không trả hash hoặc token phiên cho API danh sách.

## 6. Dữ liệu và API dự kiến

Bảng sở hữu: `staff_users`, `roles`, `user_roles`, `staff_sessions`. `audit_events` dùng chung theo ADR-0003.

| API | Dữ liệu chính / kết quả |
|---|---|
| POST `/api/v1/auth/login` | username, password → phiên cookie + hồ sơ tối thiểu |
| GET `/api/v1/auth/me` | id, displayName, roles, mustChangePassword |
| POST `/api/v1/auth/logout` | Thu hồi phiên hiện tại; retry an toàn |
| POST `/api/v1/auth/change-password` | currentPassword, newPassword; thu hồi phiên khác, tạo lại phiên hiện tại |
| GET/POST `/api/v1/staff` | Danh sách phân trang / username, displayName, initialPassword, roles |
| PATCH `/api/v1/staff/{id}` | displayName, active, expectedVersion |
| PUT `/api/v1/staff/{id}/roles` | roles[], expectedVersion |
| POST `/api/v1/staff/{id}/reset-password` | temporaryPassword, expectedVersion; bắt buộc đổi lần sau |

## 7. UI và lỗi

Màn hình đăng nhập mobile/tablet; trang quản trị nhân viên desktop/tablet. Hiện lỗi dễ hiểu: đăng nhập sai (401), hết phiên (401), thiếu quyền (403), tài khoản/admin cuối cùng hoặc version xung đột (409), dữ liệu không hợp lệ (422). Điều hướng về đăng nhập khi hết phiên nhưng không tự gửi lại lệnh ghi chưa rõ kết quả.
